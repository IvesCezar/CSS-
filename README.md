# 🏁 Nitro Racing

Uma página web estática criada com **HTML5** e **CSS3**, com temática automotiva e foco na apresentação de veículos esportivos.

O projeto apresenta um catálogo visual de carros em cartões, com imagens, descrições e botões de compra ilustrativos. O layout utiliza cores inspiradas no universo automobilístico, efeitos de interação e organização flexível dos elementos.

## 🚗 Veículos apresentados

- Nissan Skyline
- Mazda Miata
- Toyota Supra
- Dodge Challenger
- Honda Civic
- Mitsubishi Lancer

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo da página.
- **CSS3** — estilização, layout, cores, sombras e efeitos de interação.

## ✨ Recursos

- Cabeçalho com identidade visual Nitro Racing.
- Catálogo de veículos organizado em cartões.
- Layout com Flexbox e quebra automática de linha.
- Efeito de zoom ao passar o cursor sobre os cartões.
- Efeito visual nos botões durante o hover.
- Imagens dos veículos com ajuste de enquadramento usando `object-fit: cover`.

## ▶️ Como executar

1. Faça o download ou clone este repositório:
   ```bash
   git clone https://github.com/IvesCezar/CSS-.git
   ```
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.

Não é necessário instalar dependências ou configurar um servidor para visualizar a página.

## 📌 Observação

Este projeto tem finalidade de estudo e prática de desenvolvimento front-end. Os botões **Comprar** são elementos visuais e não realizam compras ou transações.
